Vespucci 22.2 BETA Highlights

2026-11-19

Locale no longer added to changeset tags automatically

With this release we stop adding a locale tag automatically to changesets. If you want to continue to provide this to people inspecting your edits, you can simply add it to the persistent tags in the upload dialog. The change is reflected in the updated version of our privacy policy.

Updated image- and photo viewer

The photo viewer now supports adding links to OSM objects from the viewer for Panoramax and Mapillary images, you will need to have one OSM Element selected in the map view for this. Uploading an image from the vier will automatically try to add a link. Further the info modal displays the source url for Panoramax and Mapillary images and, displays positioning precision and dilution of precision values if available. See image- and photo viewer.

Additional GPX layer functionality

Clicking on/selecting a GPX segment (note that a GPX track can consist of multiple segments) will now display a dialog that allows you to download OSM data along the segment or convert it in to an OSM way.

As directly converting a GPX segment to an OSM Way is typically not a good idea, you will be asked to set filters before the operation, the Jitter-Filter removes small amplitude jitter, for example created by stopping for a longer time, and the Ramer-Douglas-Peucker Simplification will simplify the overall geometry of the segment before creating the Way.

Changed elements highlight

Newly created or modified ways and nodes are now highlighted in light blue, the colour is defined in the map styles.

Crash reports saved locally

Crash reports will now be saved locally if submitting them fails (ACRA will retry these till they can be sent), and you can change the behaviour to always keep a local copy with a Advanced preference.

Reminder: Android 5.0 and 5.1 EOL announcement

With next years major version 23 we will be dropping support for Android 5 and 5.1. These Android versions will be a dozen years old in 2027 and google has now dropped support for them in many of the libraries we rely on, with other words we don't really have a choice.

Other behaviour changes

  • Renamed Find to Find place
  • Add configuration for OpenGeofiction API and OAuth2 client ids
  • Ramer-Douglas-Peucker simplification is supported for OSM Ways
  • Separate snapping behaviour for creating ways vs areas

Miscellaneous

Upgrading from previous versions

As a general precaution you should upload any pending changes before updating, particularly if you are upgrading from any major version that doesn't immediately precede this one.
